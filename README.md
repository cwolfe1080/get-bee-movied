# get-bee-movied
Choose whatever Scratch project your heart desires and put the entire bee movie script in the comments!

## How it works and how to use  
It's pretty simple. Run the python script with scratchattach and other required libraries. From there you'll enter the target scratch project and your scratch login credentials and the rest of the python script will run. In order to prevent comments from not going through, it may take around 10 minutes to comment the entire bee movie script into the project.
## NOTE:
This python script **does not** store any login credentials or project information. If you know a thing or two about python, you can scan through the entire script and see that no Scratch credentials are stored nor sent anywhere.
