# get-bee-movied
Choose whatever Scratch project your heart desires and put the entire bee movie script in the comments!

## How it works and how to use  
It's pretty simple. Run the python script with scratchattach and other required libraries. From there you'll enter the target scratch project and your scratch login credentials and the rest of the python script will run. Keep in mind that the process of commenting the entire bee movie script into one process while avoiding bans and cooldowns usually takes around 30 minutes for most scratchers.
## NOTE:
This python script **does not** store any login credentials or project information. If you know a thing or two about python, you can scan through the entire script and see that no Scratch credentials are stored nor sent anywhere (except for Scratch).

## Bans, safety, and risks
From what I know about, executing this script does not violate the Scratch community guidelines. However, it is possible to receive temporary bans while executing this script. When you run the script, you become fully responsible for the actions that it executives and the consequences to those actions.

## People are spamming my project with the bee movie script
If you find that your projects are being target with this script and you'd like to be blacklisted, so that this script cannot be run on any of your projects, feel free to contact me. That being said, this is an open source script, and anyone can remove your name from the blacklist before executing the project. I have made the script to execute so that all parts of the script stem from (or are replies of) one single parent comment, meaning that if you'd like to delete comments containing the bee movie script, you only need to delete the parent comment and all of replies to the parent comment will be deleted. I'm also thinking about making a get-un-bee-movied script, which automatically scans through your comments and finds the ones containing the first part of the bee movie script, and then deletes that comment and its replies. If you'd really like me to make this, again, please reach out, and I'll try to do so as fast as possible.
